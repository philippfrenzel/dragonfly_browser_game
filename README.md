# Solar-Panels auf dem Dach

Ein Browser-basiertes Sokoban-Puzzle-Spiel für Messen und Events.

## Spielbeschreibung

Schiebe Solar-Panels auf die markierten Positionen auf dem Dach! Ein klassisches Sokoban-Puzzle mit 5 progressiv schwierigeren Leveln, perfekt für Messen und Präsentationen zum Thema erneuerbare Energien.

## Features

- 🎮 **5 Level** mit steigendem Schwierigkeitsgrad
- ☀️ **Solar-Panel Mechanik**: Schiebe Panels auf Zielmarkierungen
- 🏠 **Hindernisse**: Dachfenster, Schornsteine und Schatten
- 🎨 **90er-Jahre Retro-Grafik**: Pixeliger Charme mit modernem Design
- 💾 **Beste Züge**: Automatisches Speichern der besten Züge pro Level
- ↩️ **Undo-Funktion**: Züge rückgängig machen mit der Z-Taste
- 📱 **Responsive**: Funktioniert auf Desktop und mobilen Geräten

## Steuerung

- **Pfeiltasten** oder **WASD**: Bewegen des Arbeiters
- **R**: Level zurücksetzen
- **Z**: Letzten Zug rückgängig machen
- **Enter**: Spiel starten

## Installation

Einfach die `dragonfly_game.html` Datei im Browser öffnen - keine Installation notwendig!

## Level

1. **Einfacher Start**: Tutorial-Level zum Kennenlernen der Mechanik
2. **Hindernisse**: Einführung von Dachfenstern und Schornsteinen
3. **Schatten-Labyrinth**: Komplexere Rätsel mit Schattenfeldern
4. **Dachgarten**: Anspruchsvolle Kombinationen von Hindernissen
5. **Meister-Herausforderung**: Das ultimative Puzzle für Experten

## Hinweise

- Panels können nur **geschoben**, nicht gezogen werden
- Vermeide es, Panels in Ecken oder gegen Hindernisse zu schieben
- Die Schatten sind begehbar, aber erschweren die Sicht

## Technologie

- Pure HTML5, CSS3 und JavaScript
- Canvas-basiertes Rendering
- Keine externen Abhängigkeiten
- LocalStorage für Highscores
